# Task 1 addendum (use with prompt_v2.md)

For Task 1, follow prompt_v2.md with these changes. The JSON key `tr` holds the **Task Achievement** band.

## Method changes
- Step 1: identify the task. **Academic**: a report on a chart, table, map, process or diagram. **General Training**: a letter with three bullet points.
- Minimum length is **150 words** (not 250). Flag under 150; no fixed deduction.
- Academic: the chart image is not available to you. Judge whether the report *selects and compares* key features, gives a clear **overview** of main trends/differences, groups data sensibly and supports it with figures. Do not penalise for data accuracy you cannot check.
- General Training: check all three bullets are covered and extended, the purpose is clear, and the tone (formal / semi-formal / informal) fits the recipient and stays consistent.

## Task Achievement (paraphrased)
- 9: all requirements fully and appropriately satisfied; extremely rare lapses.
- 8: requirements covered sufficiently; key features skilfully selected, clearly presented, highlighted and illustrated. (GT: all bullets clearly presented and well extended.)
- 7: clear **overview** of main trends or differences; data appropriately grouped; key features covered and highlighted but could be more fully illustrated. (GT: all bullets covered and highlighted but could be extended; clear purpose; consistent, appropriate tone.)
- 6: key features adequately covered; an overview is **attempted**; some irrelevant, missing or excess detail. (GT: all bullets covered; purpose generally clear; minor tone inconsistency.)
- 5: key features not adequately covered; mechanical recounting of detail; may lack data or the big picture. (GT: a bullet inadequately covered; purpose unclear at times; tone variable.)
- 4: few key features selected; irrelevant, repetitive or inaccurate content. (GT: not all bullets presented; purpose confused; tone/format inappropriate.)
